# osu! Kai

このスクリプトでの不具合は、osu!公式に報告しないでください

[![osu! Kai をインストール](https://img.shields.io/badge/install-osu!%20Kai-ff66aa)](https://raw.githubusercontent.com/SayamaKaede/osu-kai/main/osu-kai.user.js)

[Tampermonkey](https://www.tampermonkey.net/) を入れたブラウザで、上のボタンを押してインストールします

- フレンドを相互・片思いで絞り込み
- 前回から相互になった人・相互じゃなくなった人・追加した人・名前が変わった人を表示
- フレンドリストから名前で検索
- 譜面ページに、選んでいる難易度の自分のプレイ回数を表示
- タイトル・アーティストにマウスを合わせると、もう片方の言語の表記を表示

## English

Please do not report problems with this script to osu!

[![Install osu! Kai](https://img.shields.io/badge/install-osu!%20Kai-ff66aa)](https://raw.githubusercontent.com/SayamaKaede/osu-kai/main/osu-kai.user.js)

Install [Tampermonkey](https://www.tampermonkey.net/), then press the button above

- Filter friends by mutual and non-mutual
- Show who became mutual, stopped being mutual, was added or changed their name since last time
- Search your friend list by name
- Show your own play count for the selected difficulty on beatmap pages
- Hover the title or artist to see the other language
